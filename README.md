    *   ORAI1/STIM1可作为改善脑血流、防治认知功能障碍（如血管性痴呆、脑缺血）的潜在药物靶点；ORAI3则可作为焦虑症干预的新靶点。但需注意，全身性调节可能导致不同亚型间功能失衡，开发亚型选择性调节剂（如ORAI1/STIM1激活剂或ORAI3抑制剂）可能具有治疗潜力。
